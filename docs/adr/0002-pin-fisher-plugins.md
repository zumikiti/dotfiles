# Pin fisher plugins with a committed fish_plugins

We will bring `fisher` plugins under the same Version-managed Installation and Manual Update Policy already applied to the `flox` First Wave. The plugin list lives in `fish/fish_plugins`, committed to this repository and symlinked to `~/.config/fish/fish_plugins`, and every entry is pinned to a full commit SHA rather than a moving tag or branch. The initial set is `jorgebucaran/fisher` (4.4.8, `a04308be92daa6cfecdbb0ca58b1e8508664cff2`) and `oh-my-fish/theme-bobthefish` (`72a89d424644d087c182843a48fbf0a43c796f31`).

`fisher` is bootstrapped from the same pinned SHA recorded in `fish/fish_plugins` instead of the previous `curl https://git.io/fisher | source` path, so the installation source and version are reproducible from files committed to this repository. Updates change only through an explicit user-initiated edit to the pinned SHA followed by `fisher update`, with the result committed — `fisher update` is never run to pull moving refs. This supersedes the deferral of `fisher` recorded in [ADR 0001](0001-flox-first-wave-for-cli-tools.md), while `tpm`, `lazy.nvim` bootstrap behavior, and other `curl | bash` installer paths remain deferred.
